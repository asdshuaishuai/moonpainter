# demo 手工功能测试清单（点哪里 → 期望什么）

给**人**用的：把浏览器里每一处入口点一遍，逐条对照"期望"。机器侧的门禁
（`./verify.sh`、`./build_demo.sh`）管的是"代码没坏"；这份清单管的是
**"产品还能用"**——包括只有人眼才看得出的东西（画布位置、缩放、拖动、
拖拽落点、面板刷新）。

## 0. 先确认在测哪一版（不做这步，后面所有现象都可能指向别的地方）

```bash
./build_demo.sh          # 构建（含 Node 侧自检 + 页面接线核对）
./serve_demo.sh          # 固定端口 8137 + Cache-Control: no-store
# 浏览器开 http://127.0.0.1:8137/
```

- [ ] 顶栏右上角徽标显示 `引擎 v0.1.0 · mpd/v1 · 构建 <commit> <时间> · wasm <sha8>`；
      与 `./serve_demo.sh` 启动时打印的 `dist 构建元数据` **一致**。
      **对不上就停下来**：要么打开的不是这个目录，要么构建没跑（徽标写
      "这页不是 ./build_demo.sh 产出的"就是在说这件事）。
- [ ] 徽标里的 `commit` 是你刚提交/刚改的那一版（`git log -1 --oneline` 对一眼）。

## 0.5 哪些**已经**被机器覆盖了（这些不必你手动重跑）

`./build_demo.sh` 里的点击穿透门用哑 DOM 壳加载**真的 demo.js**，直接调页面
处理器、再从引擎把状态读回来：**66 条断言**，覆盖可点处理器 **74 个里的 70 个**。
已经在管的有：

- 面板 18 颗按钮 + 4 条"缺输入必须明说"的拒控；
- 保存/导出（真的把非空字节交给下载）、顶栏徽标两条（有元数据/没元数据）；
- 图层的选中高亮/隐藏、编辑动作（撤销/重做/删除/置顶/置底/方向键/旋转/翻转/透明度）；
- 属性面板 x/y/w/h、标签（打得上也摘得下）、父级（进组/解组）；
- 文字（落点/建层/改内容后盒子跟着变/改字号）、蒙版（加/反选/摘）；
- 调整层（改算子/改数值/一键滤镜）、画笔落笔、新建与改画布（含越界拒绝）；
- 裁剪（取消不生效/应用真的变小）、缩放/重刷/统计/不透明度气泡/AI 面板折叠。

引擎侧另有 346 条 native 测试、344 条 wasm-gc 测试、235 条变异（232 条被抓住）。

**所以下面的清单请重点走"机器测不了"的那部分**：

| 只有人能测的 | 为什么 |
| --- | --- |
| 真实鼠标拖拽的手感（跟手、笔触连贯、框选尺寸） | 驱动器只有坐标，没有指针事件的时序与像素 |
| **浏览器把 File 解成 PNG** 这一步（`__drop`/`__file_sel`/`__mpd_sel`/`__img_swap`） | 驱动器已经用**真 PNG 字节**走完了导入的其余全部链路（落点/画布/1:1），只剩"Image 解码 + canvas 转 PNG"要真的浏览器（HEIC 这类格式差异就在这一层） |
| 画布上"糊不糊、对不对"（1:1 锯齿、蒙版羽化过渡、旋转后的边缘） | 机器只能比 sha 与采样点，观感要靠眼睛 |
| 接**真实** LLM 端点修图 | 需要真的 Base URL + API Key（拒控已机器覆盖，正控没法） |
| 换浏览器（Safari / Chrome / Firefox） | wasm 装载、字体渲染、下载行为各有差异 |

## 1. 一键功能自检（右栏最底下「🩺 自检 · 调试」）

- [ ] 点「🧪 功能自检：跑一遍功能清单」→ 报告区出现一张表，**每一行都是 ✓**，
      顶部一行绿字写着"`N` 条全过 ✓"。状态栏同一句话。
- [ ] 表里每行三列：功能 / 期望 / 实测。**实测列不是空的**（那里是引擎原话：
      sha 前 12 位、颜色、指纹）。空列 = 断言根本没跑。
- [ ] 自检跑完，**你当前画布上的图没变**、图层列表没变（清单跑在另一份引擎上）。
- [ ] 故意让它红一次（可选，验证判据还咬得住）：先在控制台执行
      `set-style r1 opacity=1`，再点自检——报告应当**照旧全过**（自检开场就 `new`，
      不吃当前文档）。真正的红只可能来自代码回归，不来自你的文档状态。

失败时怎么办：把那行「实测」里的**引擎原话**连同徽标上的 commit 一起记下来。
面板已经把"命令被拒（前半句是命令、箭头后是引擎的拒绝理由）"与"命令成功但
断言不成立（后面跟期望与实测）"两种失败分开写了——先看是哪种。

## 1.5 导入一张照片（**这个工具的主线，先走这条**）

- [ ] 左栏点「📷 导入图片」，或把一张照片**直接拖进**画布 → 日志先出现
      `📷 正在读取照片…`（大图要几秒），随后
      `📷 已打开 xxx.png（画布 W×H，1:1 不缩放）`：
  - **照片不许变形**：竖版进来还是竖版、横版还是横版（旧版本会把它塞进 600×450）；
  - **画布跟着照片**：照片比画布大 → 画布被放大到照片尺寸、照片从 (0,0) 铺满；
    照片比画布小 → 画布不动、照片居中；
  - 长边超过 **4096** 的照片会先说一句「已从 8064×6048 缩到 4096 以内」再进来
    （引擎的可渲染上限）；
- [ ] 如果手边有 **iPhone 的 HEIC** 照片（Chrome 里多半解不开）→ 应当**明说**
      「浏览器解不开这张图（…先在「照片」里导出/另存为 JPEG）」，而不是点了没反应；
- [ ] 导入完那张照片**已经被选中**（图层面板高亮）→ 右栏「调整·美颜」点一下，
      效果要作用在**照片**上；
- [ ] 存成 `.mpd` 再「📂 打开」→ 照片与画布尺寸都回来；
- [ ] 导出 PNG → 尺寸 == 画布尺寸，且**照片内容完整**（不是只有左上角一块、
      也不是被压扁的）。

## 2. 顶栏（新建 / 打开 / 存 / 导出 / 撤销 / 重做 / 缩放）

- [ ] 「＋ 新建」→ 画布变白，图层列表只剩示例场景之外的东西（或空），状态栏有提示。
- [ ] 「↩ 撤销」/「↪ 重做」：画一个矩形 → 撤销 → 矩形消失；重做 → 回来。
- [ ] 「💾 存」下载 `.mpd`；再「📂 打开」同一个文件 → 图与图层列表和存之前**一样**，
      徽标不变（文件里没有构建信息，变了才是 bug）。
- [ ] 「🖼 导出」下载 PNG；用系统看图确认内容与画布一致。
- [ ] 缩放：`－`/`＋`/`适应`/`1:1` 各自点一遍，图**居中且不糊**（`1:1` 时像素一望即知）。

## 3. 工具条（左栏，每个工具点一遍）

| 工具 | 操作 | 期望 |
| --- | --- | --- |
| 🖐 移动 | 图层列表选中一层 → 画布上拖动 | 层跟着走、属性面板 x/y 实时变；松手后撤销能还原 |
| 🖌 画笔 | 按住拖动 | 自动建"画笔层"（没有就建），线跟着鼠标走，松手成一条笔迹 |
| 🧽 橡皮擦 | 在画笔层笔迹上拖 | 只擦笔迹、不擦别的层（擦到非画笔层应当没反应或明确提示） |
| 💧 吸管 | 点画布任意处 | 状态栏给出该点颜色；颜色面板的取色值跟着变 |
| T 文本 | 点画布 → 输入框 | 文本落在**点击处**；含空格的字（`Hello World`）原样保留，不变成下划线 |
| ✂️ 裁剪 | 拖一个框 → 「应用」 | 画布尺寸变成框的尺寸（状态栏/属性面板对得上），图被裁而不是被缩 |
| ▤ 矩形 / ⬭ 椭圆 | 拖一个框 | 落在拖出的框内（不是左上角起一个固定大小） |
| 折线 / 多边形 | 逐点点击 + 双击/回车收尾 | 顶点就是你点的地方；已点未收尾时状态栏有提示；取消不留下半个层 |

- [ ] 每个工具切过去，状态栏都有一句"这个工具怎么用"。
- [ ] 拖拽过程中画布上有预览（矩形/椭圆/裁剪框），松手才落层。

## 4. 图层面板（右栏上部）

- [ ] 点一层 → 高亮；画布上该层出现**选中线框**（带序号的细框）。
- [ ] 选中后按 `rotate 30`（控制台）→ 线框**跟着转**（不是还框着原来的轴对齐盒子）。
- [ ] 把一层放进组、再转组 → 线框同样跟着组的变换走。
- [ ] 眼睛图标：隐藏 → 图层从画布消失、`sample` 该点变白纸；再点亮 → 回来。
- [ ] 拖拽图层改层序 → 画面遮挡关系跟着变（上移/下移按钮同理）。
- [ ] 「编组」选中多层 → 成一个组；「解组」→ 回到各层，**画面逐像素不变**。
- [ ] 删除 → 层消失；撤销 → 回来（含蒙版/标签/透明度，别只回来一个空壳）。
- [ ] 蒙版：给层加矩形蒙版 → 蒙版外的部分**不画**；反相 → 反过来；清除 → 恢复。

## 5. 属性面板

- [ ] 换层时面板跟着换（不残留上一层的值）。
- [ ] 拖 x/y/w/h/旋转/不透明度 → 画面实时变，`query-layer` 报得出的数值跟着变。
- [ ] 文本层：改文字/字号 → **盒子跟着内容走**（文字不溢出盒子、不糊成一团）。
- [ ] 调整层：改算子/数值 → 画面变；把值调到 0 时 `lint` 会报"空操作层"。
- [ ] 能力（caps）：选中一条**线**不会有"圆角"这类控件（引擎说这个 kind 没这个效果）。

## 6. 自检 · 调试面板（16 条引擎命令的人类入口）

- [ ] 「lint 检查」→ 面板里是 `violations` 明细；刚建好的示例场景是 `0`。
- [ ] 把某个文本层内容清空，再点「lint 检查」→ 出现"空文本层"那条违规。
- [ ] 「编辑历史」→ 列出 `undo`/`redo` 栈；「全图普查」→ 桶统计；「探一点(10,10)」→
      出该点的边缘置信度与 membership。
- [ ] 「命令字典」/「工具清单」/「选择子清单」→ 面板里铺出内容（长文会截断，
      这是有意的；要看全文就自己滚）。
- [ ] 「选区预览」→ 画布上铺出**覆盖图**（选区覆盖到哪一目了然），面板里同时有
      覆盖率数值。**下一次操作/渲染会恢复原图**（状态栏会这么说）。
- [ ] MVSL：把 `{"version":1,"ops":[],"guards":[]}` 贴进文本框 → 「装表」→
      「看表」列得出来；「影响证书」→ 有 `changed`/`leak_ratio`；「断言」→ ok；
      「清表」→ 画面回到没装表的样子。
      再把一段**真的会改画面**的编辑表贴进去（`sel-schema` 里有算子清单），
      「装表」后画面必须变。
- [ ] 元参数：key/value 填 `style` / `moody` → 「写元参数」→ 「列元参数」里有它；
      「删元参数」→ 消失。**画面不该因为元参数变**（元参数是给模型的上下文）。
- [ ] 控制台：输入 `render 400 overlay=1` → 画布上出现带序号线框的图；
      输入 `query-layer <选中层>` → 回包铺在面板上；输入一条拼错的命令
      （如 `rendr 10`）→ 状态栏红字说"未知命令"，**不是静默无事发生**。

## 7. AI 面板（把「🤖 AI 修图」展开）

> 需要可用的模型配置；没有 provider 时这一节可以跳过（面板会明说不通）。

- [ ] 发一句"在右上角加一个渐变圆形徽章"→ 逐条出现"🤔 AI 思考 / 🔧 执行 / ✅"，
      **不是**等一分钟才一股脑出来。
- [ ] 回合结束后画布上真的多了东西，图层面板出现新层。
- [ ] 追问一句"把背景换成冷色调"→ 同一个会话继续（不是重开一张图）。
- [ ] 工具失败时面板能看到引擎的**拒绝原话**（不是"出错了"三个字）。

## 8. 边界与错误（都要**说人话**，不许静默）

- [ ] 打开一个不是 `.mpd` 的文件 → 明确报错，不动当前文档。
- [ ] 控制台执行 `add-rect x=abc` → 报"不是数字"；`set-style r stroke_w=-3` → 报下界；
      `add-rect w=0` → 报正数要求；`tag r ""` → 报空标签。
- [ ] 画布外采样 `sample 9999 9999` → 报超出画布（而不是给一个假颜色）。
- [ ] 文本层上执行 `add-adjust` 之外的 kind 专属命令 → 报"这个 kind 不支持"。

- [ ] 跑一次 `./verify.sh` 与 `./build_demo.sh`，确认不是你本地状态的问题。
